# Equipment texture pipeline

- Keep inference local; prefer MLX on Apple GPU and verify the actual device.
- Quality and preservation of painted detail outrank speed or model size.
- Treat Retail IDs as lookup keys, never proof of an updated compatible asset.
- Separate body components, object materials and baked NPC atlases.
- Keep game assets, generated comparisons, weights, caches and binaries private.
- Require explicit input paths, pinned hashes and reproducible model parameters.
- Preview installation first. Preserve process checks, hashes, no-symlink checks,
  isolated patch ownership and guarded rollback. Never modify race models or settings.
- Default tests use synthetic inputs. Label offline and gameplay evidence separately.
- Use Conventional Commits. Do not publish or push without explicit authorization.
